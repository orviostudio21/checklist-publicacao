# Checklist de publicação

Checklist interativo para revisão de sites, com progresso e armazenamento local. Não substitui uma auditoria técnica completa.

**Projeto demonstrativo da Orvio Studio.** Não representa um cliente real.

## Executar
Abra index.html em um navegador moderno. Sem instalação ou dependências.

## Tecnologias
HTML, CSS e JavaScript.

## Personalizar
Conteúdo em index.html, estilos em style.css e comportamento em app.js.

## Limitações
Sem backend, pagamentos ou envio de formulários. Valores e marcas são demonstrativos. Revise antes do uso em produção. A identidade Orvio Studio não é cedida para uso como sua própria marca.
